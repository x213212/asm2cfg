# Modular graph refactor and jump-table recovery

Work is based on the x213212/asm2cfg fork, in branch
`refactor/modular-graphs`. The separate existing `asm2cfg2` checkout and its
uncommitted changes were preserved. Publication targets only the
`refactor/modular-graphs` branch in that fork; main and upstream issues are unchanged.

## Result

- RISC-V support, SCC loop coloring, SVG output and the comparison page are retained.
- Parsing, architecture rules, CFG/call collection, algorithms, rendering and reports
  are separate modules. The previous monolithic implementation is replaced.
- CLI uses supplied paths, supports multiple functions and no longer rewrites
  assembly inputs into hardcoded machine-specific paths.
- Real instructions keep their addresses and source line numbers; source annotations
  remain attached data rather than fabricated instructions.
- Calls and intraprocedural CFG edges are represented separately. Unresolved indirect
  calls and branches are explicit.
- Tarjan handles self loops, two-node cycles and deep graphs without recursion.
- Immediate dominators address upstream issue #24. SCC membership is not used as a
  substitute for dominance.
- Common guarded x86 jump tables are recovered from matching immutable ELF bytes or
  an objdump section dump. Every entry is validated, and case edges participate in
  the rebuilt CFG and dominance analysis.
- HTML is standalone with embedded SVGs. The Traditional Chinese comparison viewer
  has independent file lists, zoom, fit and optional synchronized scrolling, without
  third-party browser dependencies.
- Graphs retain full assembly and strong loop colors, with left-to-right layout,
  increased spacing, L1/L2 region labels, and red back edges showing their addresses.
  Top-to-bottom layout remains available via `--direction vertical`.

## Validation

Before refactoring, the original parser/regex tests produced 22 passes, 7 failures
and 1 expected failure. After the refactor and jump-table extension:

- **95 tests passed**, with no expected failures, including GDB integration.
- SCC and immediate dominators were checked against NetworkX on 100 seeded graphs.
- A 10,000-node cyclic graph completed without a recursion failure.
- All seven original example disassemblies parsed successfully.
- Compiler-generated PIE relative tables and non-PIE absolute tables were recovered
  in both AT&T and Intel syntax. GDB stepped through each of eight switch branches
  and matched every recovered target. A linked ELF32 absolute-table fixture also passed.
- Missing, truncated, unguarded and invalid table inputs retain unknown targets.
- flake8, git whitespace checks and wheel packaging passed.
- Headless Chromium loaded the report images, independently loaded both comparison
  panes, and verified zoom/fit with no JavaScript errors or external network requests.

Local five-run medians measured SCC plus immediate dominators at approximately
1.78 ms for 1,000 cyclic nodes and 20.60 ms for 10,000 cyclic nodes. The existing
1,079-instruction RISC-V matrix example parsed and analyzed in approximately
17.08 ms. These are local measurements excluding Graphviz layout and are not
an old/new speedup claim.

## Remaining scope

Jump-table recovery is bounded to 4,096 entries and supported guarded x86 patterns.
Arbitrary indirect targets, mutable tables, unlinked relocation-bearing objects,
RISC-V/ARM jump tables, exception edges and path-feasibility proof remain outside
the implemented recovery. No binary rewriting backend is included.
